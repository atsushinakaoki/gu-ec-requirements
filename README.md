## この文書について

事業環境（ファーストリテイリングの「情報製造小売業」構想、GUの事業モデル）を
先に押さえたうえで、実際のサイトを観察して要件に落としています。

- 観察できた事実と推論を区別して記述
- 機能間で整合していないと思われる箇所は【整合上の論点】として明示（18箇所）
- 法務の観点から、景品表示法・特定商取引法・個人情報保護法まわりに言及
